# طب الطوارئ الاتصالي — جدة

عرض توعوي ثنائي اللغة يعمل من الملف `index.html`. الصور والخطوط اللازمة للعرض مضمّنة في الملف. فيديوهات X تحتاج اتصالاً بالإنترنت، وقد تتأثر بقيود المنصة. لم تُضمّن ملفات فيديو محلية بعد.

## الرفع إلى GitHub

أنشئ مستودعًا فارغًا، ثم ارفع `index.html` و`README.md` و`.gitignore` من هذا المجلد. يستثني ملف `.gitignore` بقية ملفات المجلد من الإضافة الاعتيادية إلى Git؛ الملفات المتتبعة مسبقًا لا يستثنيها تلقائيًا. إذا أضفت فيديوهات محلية مستقبلًا، عدّل الاستثناءات وأضف ملفات الفيديو التي تريد نشرها فقط.

## Cloudflare Pages

- اختر **Workers & Pages → Create → Pages → Import an existing Git repository**.
- اختر مستودع GitHub وفرع الإنتاج (مثل `main`).
- إعداد الإطار: **None**، وأمر البناء: `exit 0`، ومجلد مخرجات البناء: `.` (جذر المستودع).
- بعد النشر، اختبر العربية والإنجليزية والتنقل والحالات التفاعلية والصور والفيديوهات على الرابط الناتج.

العرض يتضمن صورًا وشعارات وبيانات ظاهرة للجمهور داخل `index.html`. راجع ملاءمة نشرها وحقوق استخدامها وصحة معلومات الخدمة قبل جعله متاحًا للعامة. توجد صورة تحتوي على رمز QR غير متحقق من وجهته؛ استبدله قبل الاعتماد عليه.
